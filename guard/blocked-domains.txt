# Jarvis guard: blocked domains.

# Format: <host> <rule-id> [path-regex]

#             (only useful with a path-regex).

#   path-regex optional, JavaScript regex tested against the lowercased URL path.
#             When present, only matching paths on that host are blocked.
# Lines starting with # and blank lines are ignored.
# Changes to this file need Leo's explicit approval (docs/DESIGN.md section 3).
