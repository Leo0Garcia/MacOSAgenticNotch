# vault-template/

Starting structure for `~/Jarvis-Memory`. `bun librarian/src/cli.ts init-vault` copies it into place and never overwrites a file that already exists. This README is not copied.

- `Me.md`: who Leo is and how he likes things.
- `Index.md`: regenerated by the librarian, wikilinks to every note.
- `Projects/_template.md`: the registry entry. Frontmatter `status` (`active`, `paused`, `archived`), `repos`, `people`, `slack_channels`, `claude_project_url`; sections `Done`, `To do`, `Needs Leo`.
- `People/_template.md`: one note per person.
- `Log/YYYY-MM-DD.md`: one line per run, appended by the librarian.

`{{name}}` is replaced with the note's name when a note is created from a template.
